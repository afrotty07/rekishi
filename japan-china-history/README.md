# 日本の対外関係史 — 大学受験インタラクティブ年表

縄文〜平成の **361項目** を、日中・日朝日韓（朝鮮半島）・日露日ソ・日英・日米の5地域で比較する静的Webサイトです。

## 機能
- 5関係史の単独表示・複数地域比較（既定は日中）
- 時代、テーマ、重要度、キーワードによる絞り込み
- 暗記モード、各出来事の入試ポイント、保存、印刷
- 現在の表示条件に基づくCSV出力（元データはJSONファイル）

## データ構成
- `events.json` — 従来の日中関係137件
- `events-kr.json` — 朝鮮半島関係69件（1948年以降の南北を区別）
- `events-ru.json` — ロシア・ソ連関係48件
- `events-uk.json` — 英国関係44件
- `events-us.json` — 米国関係63件
- `template.html` — Webアプリのテンプレート。 `__EVENTS__` に結合データを挿入
- `build.py` — 再生成スクリプト
- `index.html` — 完成したWebサイト

```bash
python3 build.py
```

## 注意
受験学習用の編集教材。関係史は国家間の正式な外交だけでなく、戦争・通商・文化交流・第三国を介した影響を含みます。評価が分かれる歴史問題は各国の主張・史料を区別してください。平成までを対象とし、令和の事項は含めていません。

参考資料：国立歴史民俗博物館、国立公文書館、アジア歴史資料センター、外務省（各国・地域）、国立国会図書館デジタルコレクション。
